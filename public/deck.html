The Problem

Multi-agent coordination on Somnia has no on-chain layer

  • Every multi-agent workflow today relies on a centralized off-chain server to decide what runs next
  • No verifiable record of which agent produced which result, or why a step was skipped
  • If the coordinator goes down or acts maliciously, there is no audit trail
  • Users cannot compose agents from different builders into a single trustless pipeline
The Solution

A smart contract that orchestrates agents

  • PipelineRegistry.sol — an on-chain FSM that stores pipeline definitions, tracks execution state, and emits events
  • Conditional branching — agents can output EXECUTE or SKIP, and the contract enforces the branch path
  • Relay coordinator — listens to StepCompleted events and dispatches the next agent. The contract is the source of truth, not the relay
  • Agent Registry integration — compose pipelines from 56+ agents already registered on Somnia

Features

What makes SomniaFlow different

On-Chain FSM

The smart contract stores every pipeline step, agent assignment, and execution result. The blockchain is the coordinator, not an off-chain server.

Conditional Branching

The Risk Evaluator outputs EXECUTE or SKIP. Downstream steps respect the decision, and the branch path is permanently recorded on-chain.

Pipeline Composer

Build custom pipelines from the UI. Choose agents, set conditions, deploy and fund on-chain. No code required.

Real-Time Streaming

Server-Sent Events stream every step completion to the frontend as it happens. Watch agents coordinate live.
